# Resistance: The Fall of Europe

A mod for **Darkest Hour Full** that adds the Chimera from Insomniac's *Resistance* games to a 1933 campaign. It starts with a closed zone in Siberia and an outbreak at Norilsk. From there the Hive takes the Soviet Union, breaks out into Europe, reaches the Channel and tries to cross it.

It adds:
- a new scenario, *Resistance: The Fall of Europe (1933)*, with the Chimera (`UA0`) as a playable country;
- about 5,700 events: the outbreak, the Soviet collapse, the breakout stages, infection and occupation, refugees, towers, the Burrowers, and the invasion of Britain;
- Chimeran technology, units, brigades, doctrines, a cabinet, leaders and research teams;
- AI files that retarget the Hive as the story advances;
- new art: flags, event pictures, tech pictures, unit pictures, portraits and map sprites.

## Installing

1. Install **Darkest Hour** and patch it to **1.05.2**. Earlier versions crash on the Chimera's country tag, because the `UA0`–`UF9` tags only exist from 1.05.
2. Install **DH Full** on top of it.
3. Make a **copy** of the DH Full folder for the mod.
4. Download the mod zip from [Releases](../../releases) and unpack it over that copy, overwriting files.
5. Start the game from the copy and pick the scenario *Resistance: The Fall of Europe (1933)*.

The mod ships modified copies of some DH Full files, so it must go over DH Full and not over plain Darkest Hour or another mod.

## Building from source

The mod is generated by Python scripts in `build/`, which read vanilla DH Full files and add the mod to them. The vanilla files aren't in this repository, so copy them from your own install first.

Requirements: Python 3 with Pillow and numpy (`pip install pillow numpy`).

```sh
python3 build/import_vanilla.py "/path/to/Darkest Hour Full"   # copies the vanilla files into src/
sh build/package.sh 1                                          # builds mod/ and resistance_mod_v1.zip
```

The build validates every event it writes and stops on errors.

| Path | Contents |
|---|---|
| `build/gen.py` | The entry point: techs, units, text, and the order everything is built in |
| `build/story.py`, `breakout.py`, `fall_of_europe.py`, … | The story arcs, one module each |
| `build/validate.py` | Checks the generated events (ids, commands, provinces, text) |
| `build/README_RESISTANCE.md` | Detailed notes and the full changelog |
| `build/DH_FACTS.md` | What's known about DH's engine behaviour, what's assumed, and how to test each assumption in game |
| `build/TESTING.md` | How to test quickly, including events worth firing from the console |
| `build/ASSETS.md` | Art formats and the status of each picture |
| `src/assets/` | The mod's own art, copied into the build as-is |
| `src/tech_raw/` | Original tech pictures, which `build/tech_pictures.py` lays into DH's tech-picture template |

## Status

This is a work in progress, and much of it is untested in game. `build/DH_FACTS.md` lists the engine behaviour the mod relies on that still needs confirming.

A few tech pictures that used official *Resistance* art are left out of this repository; those techs show borrowed vanilla pictures instead.
